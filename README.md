# 週刊ユキ — 漫画杂志风个人网站

灵感来自「あの夏が飽和する」MV 的视觉语言：黑白漫画、过曝的白光、胶片颗粒、色差、竖排明朝体、斜切分镜。
所有画面（天空、电线杆、铁丝网、作品插画、网点、集中线、音效）都是代码实时生成的原创内容，没有使用 MV 的任何截图或音乐。

## 运行

只需要 **Node.js**（你电脑上已有 v20.19）。所有依赖都装在本文件夹的 `node_modules/` 里，没有往系统里装任何东西。

```bash
npm run dev      # 本地预览：http://localhost:5173
npm run build    # 打包到 dist/，可直接部署
npm run preview  # 预览打包后的结果
```

如果换了电脑，先运行一次 `npm install`。

## 改成你自己的内容

几乎所有文字都在 **`src/content.js`** 里：名字、杂志名、标语、自我介绍、作品、能力值、经历、喜欢的东西、联系方式、背景音乐……
改完保存，浏览器会自动刷新。

- **作品集**：每一项有 `image`（大图）、`thumb`（右侧胶卷用的小图）、`credit`（作者 / 出处，填了就会显示在卡片和详情页）。
  图片放在 `public/images/works/` 和 `public/images/thumbs/`，建议转成 webp、长边 1600px 左右。
- **头像**：`avatar`（第1話的自画像）、`icon`（目次页作者コメント旁的小头像）。
- **背景音乐**：`bgm.src` 指向 `public/audio/bgm.mp3`。浏览器不允许无交互自动播放，所以访客第一次点击 / 按键时开始播放（淡入），右上角可以暂停，暂停状态会被记住。
- **联系方式**：`contact.email` 改成你的邮箱，读者明信片的「投函」按钮会打开邮件客户端发到这里。

## 部署（GitHub Pages）

仓库：`git@github.com:Chaosnap/me.git`，网址：<https://chaosnap.github.io/me/>

- 每次 `git push` 到 `main`，GitHub Actions（`.github/workflows/deploy.yml`）会自动构建并发布到 `gh-pages` 分支。
- `vite.config.js` 里用的是相对路径（`base: './'`），所以放在 `/me/` 这样的子目录下也能正常加载。
- **没有上传的文件**（见 `.gitignore`）：`RefMaterial/`、`MV/`、`public/images/works|thumbs|pads/`、`public/images/icon.webp`、`public/audio/`。
  这些素材上有其他作者 / 出版社的版权标记，背景音乐是翻唱曲，只在本地使用。线上缺少它们时，网站会自动退回：作品显示线稿插画、按钮显示拟声词、隐藏音乐按钮。
  如果你确认拥有这些作品的版权或已获授权，可以自己用 `git add -f <文件>` 加进仓库再 push。

## 文件

```
src/content.js      ← 网站内容（主要改这里）
src/render.js       页面结构
src/art.js          程序生成的线稿 / 网点 / 集中线
src/anim.js         滚动与动画（GSAP + Lenis）
src/ui.js           光标、翻页转场、昼夜切换、表单等交互
src/fx/sky.js       封面天空着色器
src/fx/jelly.js     水母（光标气泡、点击、封面、次号予告）
src/fx/bgm.js       背景音乐 + 频谱分析
src/fx/film.js      封面的胶片划痕与 VHS 扫描条
src/railway.js      第4話的铁轨与电车
src/fx/sound.js     Web Audio 合成音效
src/styles/         样式
```

`.venv/` 是用来抽帧分析参考 MV、压缩图片和转换音频的临时 Python 环境，和网站运行无关，可以直接删除。
`RefMaterial/` 里的原图没有改动，网站用的是 `public/images/` 下压缩过的副本。
